**Lease:** none (no device)

## Summary

`gate.mjs` now enforces "`real-input:ios` runs alone" across every worktree of the clone. All
five Behaviour items are done. Only `scripts/gate.mjs`, `scripts/gate-core.mjs`,
`scripts/__tests__/` and `docs/agents/gates.md` changed. `lease.mjs` and `gate-runner.mjs` are
untouched.

**Live-run source.** I chose a new marker store, not the lease claims or the background records.
Every device gate (`isDeviceGate`: harness, real-input, bench, smoke:expo/rn-cli) writes
`<git-common-dir>/nitro-ui-gate-live/<pid>.json` before it claims devices, and removes it when the
run ends (`finally` plus an `exit` hook). The other two candidates fall short. Background records
exist only for `--background` runs, since a foreground run writes its record at the end. Device
claims skip `bench`, which has no `platform`.

**Ordering.** Two gates that start at the same instant must not both see "nobody else" and run.
Admission uses the bakery algorithm. A run marks itself `choosing`, takes a ticket one past every
live run's ticket, then waits for each conflicting run that is still choosing or holds a lower
`(ticket, pid)`. Gates conflict only when one of them is `real-input:ios`, filtered or not.
Harness gates still run side by side. A later `harness:android` queues behind a `real-input:ios`
that is itself waiting, so `real-input:ios` cannot be starved.

**Ended runs.** A marker whose pid is gone counts as ended, and its file is removed when seen.

**Ceiling.** The wait gives up after 180 min by default (`NITRO_UI_GATE_ALONE_WAIT_MINUTES`). It
prints `gate: refused before the run - waited N min, the ceiling, and this run is still live:
<gate> (pid, branch, worktree, since)`, exits 1 and writes no ledger line, the same as the lease
refusals. While waiting it prints `<gate> is waiting for <runs> to end - …` whenever the set
changes, and once a minute.

**Background runs.** The detached child does the waiting, so the wait lines go to its log, and
`wait` prints them as progress. A backgrounded run that reaches the ceiling marks its record
done with exit 1, so `wait` returns 1, not 13.

**Lease test.** "hands one stale lock to one stealer" now compares `{acquire, code, stderr}`.
`stderr` is included only when an acquire fails, so a pass stays exact and a failure shows why.
