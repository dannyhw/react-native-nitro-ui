# X64 — a test's fresh launch survives a window manager that is slow to let the app go

**Branch:** `task/X64-e2e-relaunch-slow-close` (from `main` at `ec49b1d8`) · **Round:** 1 of up to 3 ·
**Lease:** `X64-ty8g0` (`emulator-5574` / Metro from the lease)

## Summary

Before each real-input test on Android, the app is now stopped and out of the window
manager's focus before the test's own `app.open()` runs. The driver's fresh launch then
finds nothing to close, so its fixed 2 s wait for the focus to move never decides the
test.

- `scripts/real-input/app-leaves-front.mjs` (`stopAndAwaitLeavingFront`) sends
  `am force-stop`, then polls every 100 ms until `pidof` is empty and `readWindowFocus`,
  fed the split `dumpsys window displays` and `dumpsys window windows` output, says the
  focused window belongs to something else (`other`). A focus on no window counts as a
  transition and is waited out. The deadline is `LEAVE_FRONT_DEADLINE_MS` = 30 s, with
  the reason in a comment: fifteen times the driver's 2 s, and an eighth of the 240 s
  test budget. At the deadline it throws, naming the focused window and its owner, plus
  any process still running.
- `example/e2e/real-input/device-read.ts` (`stopAppUntilOutOfFront`) wires it to the
  leased serial and adb server port through `adbShell`.
- `example/e2e/real-input/fixture.ts` exports a `test` extended with one fixture,
  `appOutOfFront`. The runner runs every fixture in the chain before each test, whether
  or not the test names it. All 29 `*.e2e.ts` files now import `test` from `./fixture`.
- To cover Behaviour 3, `.oxlintrc.json` has a `no-restricted-imports` override on
  `example/e2e/**/*.e2e.ts`. It rejects `test`/`describe` from `@e2e-dev/mobile` or
  `e2e`, and its message names the fixture. A new test that copies any existing file
  gets the wait. One that imports the raw `test` fails `check`. The runner has no
  config-level per-test hook, and its engine has no hook before a launch, so a fixture
  plus a lint rule is the only place that covers every test.
- `example/e2e/README.md` says the same in one paragraph.

No assertion, test timeout, retry setting, `agent-device` or `@e2e-dev/mobile` file
changed.
