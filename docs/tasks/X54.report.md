## Summary

**Android `--a11y`.** `scripts/real-input/android-run.mjs` reads the Android runner's arguments
the way `ios-run.mjs` does: `--control` and `--a11y` both repeat, and an unknown control or case
is refused with the known ids before the stamp check or any `adb` call. `--a11y <case>` alone
runs no e2e file and no tree check, only that sweep case. `--a11y` with `--control` reads the
named cases and the cases of the named controls (`a11yCaseControl` moved from `ios-run.mjs` to
`a11y.mjs` so both platforms share it). A run that names only controls still reads the whole
sweep, as it did before.

**Rerun.** Each Android sweep case now records `rerun: ['--a11y', <case>]`, and the stale-debt
check records the cases it re-reads, the way the iOS pass does. `gate-core.mjs` already turns
such checks into units, so `--rerun-failed` after a full run whose only failures are a11y cases
plans `--a11y <case>...` instead of refusing. No change to the completion logic.

**iOS stall.** `scripts/real-input/ios-xcodebuild.mjs` now runs both `xcodebuild` phases. With a
stall watch (only `test-without-building` gets one), no `Test Case '-[...]' started` line within
`STALL_LIMIT_MS` (5 min from spawning it) stops the run: `xcrun simctl terminate <udid>
nitroui.example.uitests.xctrunner`, then SIGINT to the `xcodebuild` pid this run started,
SIGKILL after 30 s if needed. The first started case disarms the timer for the rest of the run.
`ios.mjs` then throws before the report: no test started, the simulator's test service is not
answering, restarting that simulator is the fix (with the `simctl` commands). Lines split across
chunks are now joined per stream before matching.

Both new files are on the platform-only digest lists in `gate-core.mjs`. The unused
`chosenControls`/`selectControls` are removed. `docs/agents/gates.md`, CONTRIBUTING and
`example/e2e/README.md` name the Android filter and the stall limit.

Decision for review: a `--control`-only Android run keeps the whole sweep. That was a deliberate
earlier choice, and the brief did not ask to change it. `--a11y` is what narrows the sweep.
