hosted runner printed `expected [ Array(2) ] to deeply equal [ 'form-item:press' ]` and hid
both event names. `example/harness-setup.ts` is now a Jest `setupFiles` entry. It runs in the
app before each harness file and sets `truncateThreshold` to 0 on the one chai instance the
harness runtime's `expect` uses, so a failure message prints the values whole. chai is declared
in the example's devDependencies at the version the runtime already loads (6.3.0), so nothing
new is installed. No assertion changes.

40 characters together, and reads the message.
