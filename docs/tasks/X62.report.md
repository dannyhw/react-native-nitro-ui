## Summary

A red case in the Android a11y sweep now leaves its evidence in the run's output folder
(`.real-input/android`, ignored by `.gitignore`'s `.real-input/` line):

- `a11y-sweep/<case>.xml`, the dump the verdict was made on (the sweep device keeps the text of
  its last `uiautomator` read; nothing reads the tree between that dump and the verdict);
- `a11y-sweep/<case>.png`, a screenshot taken straight after.

The case's `✗` line, the one `gate.mjs` harvests into the failure excerpt, now ends with
`evidence in the output folder: final dump a11y-sweep/<case>.xml; screenshot a11y-sweep/<case>.png`.
When the name is in the tree only on zero-sized nodes it also prints
`nearest drawn ancestor of "<label>": [x1,y1][x2,y2] <class> resource-id "<id>"`, found by walking
the dump's nesting (the parsed node list carries no parents), or says that no ancestor has a box.
A failure to keep evidence is said in the same line and never replaces the verdict. A passing
case writes nothing, and the sweep clears `a11y-sweep/` at its start so the folder only holds
this run's red cases.

Two things a reviewer should read before the diff:

1. **Screenshot route.** The brief names `adb exec-out screencap -p` through `adbShell`. The
   sweep's `adbShell` returns trimmed UTF-8 text, which would corrupt a PNG, so the capture is
   `adbShell('screencap -p /sdcard/nitro-ui-a11y-sweep.png')` then `adbShell('base64 …')`,
   decoded locally. Same serial, same adb server, same route; no new device function.
2. **"A failure the deadline cuts short."** There is no 40 s sweep deadline on `main` (or on any
   local task branch). The closest thing is the scroll-probe budget in `treeShowing`, which
   ends with a red verdict on the last tree; that case is covered because evidence is kept for
   every red verdict, however the tree was reached. A case that throws before a verdict (four
   refused dumps, an unreachable tab) still keeps nothing.

`runA11ySweep` gains one optional navigation hook, `keepEvidence(control)`, called only for a
red case; `runA11ySweepOnDevice` wires it when given `out`, and `android.mjs` passes its output
folder.
